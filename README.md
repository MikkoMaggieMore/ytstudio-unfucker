# YouTube Studio Unfucker!
It unfucks the YouTube Studio livestreaming panel to look how it did from 2019-2024.

It also automatically disables vertical streaming, because who the fuck asked for that? (I'd like to "speak" with them...)

There might be things that still need to be done, so if you have any suggestions, email me at maggiebite236@gmail.com

Note: This extension may also break on occasion, I will try to fix these issues as soon as possible, but please either email me or add an issue.

Currently only works on Chromium based browsers. If you are an extension developer who can covert this into a firefox extension, feel free to as long as you credit me.

## Building
You will need Node.js and NPM for this.

It's very simple, just clone the project with<br/>
`git clone https://github.com/MikkoMaggieMore/ytstudio-unfucker.git

cd ytstudio-unfucker
`

Then, run<br/>
`npm install`

And then you can build with<br/>
`node build`

After that, the newly built project will be in "dist"
